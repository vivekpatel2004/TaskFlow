# TaskFlow

TaskFlow is a full-stack personal task management application that allows users to securely create, manage, track, and monitor their tasks from a single dashboard.

## Features

- User Registration
- User Login
- JWT Authentication
- Secure Password Hashing
- Personal Dashboard
- Create Tasks
- Edit Tasks
- Delete Tasks
- Task Status Management
- Task Priority Management
- Due Date Management
- Task Statistics
- Recent Tasks
- Profile Management
- Profile Image
- Dark Mode
- Global Notifications
- Protected Routes
